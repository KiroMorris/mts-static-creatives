# Hero Image Prompt Variations

A collection of detailed JSON prompts for generating high-quality apparel hero images. Each variation is designed to produce distinct visual styles while maintaining the professional quality needed for fashion campaigns.

---

## 1. Raw Flash Editorial Hero

**Best for:** Authentic streetwear brands, vintage-inspired collections, brands wanting an unpolished aesthetic

```json

    "model": "Female model wearing an oversized blue hoodie",
    "pose": "Lying on her back on a textured surface, head tilted slightly, one arm raised above the head, relaxed natural pose",
    "expression": "Soft, effortless, calm, slightly seductive but natural"
  },
  "camera": {
    "lens": "35mm",
    "angle": "Top-down overhead",
    "distance": "Medium full-body crop",
    "focus": "Sharp focus on face and hoodie fabric"
  },
  "lighting": {
    "type": "Direct on-camera flash",
    "style": "Harsh flash with visible shadows",
    "vibe": "90s / early 2000s raw fashion photography"
  },
  "environment": {
    "background": "Neutral textured carpet or fabric",
    "setting": "Indoor casual lifestyle"
  },
  "styling": {
    "fit": "Oversized hoodie",
    "details": "Natural wrinkles, relaxed fabric, no steaming",
    "retouching": "Minimal retouching, real skin texture"
  },
  "aesthetic": {
    "look": "Unpolished, authentic, vintage flash",
    "grain": "Subtle film grain",

  },
  "text_overlay": {
    "headline": "New colors just dropped",
    "subheadline": "THE ULTRA SOFT HOODIE",
    "font": "Clean bold sans-serif",
    "placement": "Upper left",

}
```

## Tips for Best Results

1. **Customize the subject** - Replace the garment description with your actual product
2. **Maintain consistency** - Use the same style across a campaign for cohesive branding
3. **Adjust text overlays** - Modify headlines and placement to match your brand voice
4. **Consider orientation** - These are vertical by default; adjust for horizontal hero banners as needed
5. **Layer prompts** - Combine elements from different styles for unique looks
